## Info
  
A simple CLI tic-tac-toe game built in C. It features an ultra-simple bot
opponent that is hard enough to beat to make the game interesting.
  
---
<div id="install"></div>

## Install
  
Clone this repo and run `build.sh release -n -v`. A binary will have been
generated inside a new `bin` directory.
  
``` terminal
git clone git@github.com:simon-danielsson/three-three-three.git
cd three-three-three
chmod +x build.sh
./build.sh release -n -v
./bin/*
```
